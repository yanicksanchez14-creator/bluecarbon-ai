Analyze an area

Draw a box over any coastline, up to 60 km², pick the dates and run. You get a habitat map, a carbon estimate and a PDF report.

The analysis tool runs on a free server that sleeps when nobody has used it for a while. If you see a wake-up button, press it and give it about a minute. Trouble loading? Open the tool in a new tab.
