Live analysis (beta)

Map any coastline in about a minute

  1. Draw a box over a coastline with the square tool on the map, up to 60 km².
  2. Pick the dates. A summer or full-year window gives the clearest picture.
  3. Run the analysis. Fresh Sentinel-2 imagery is processed in Google Earth Engine and mapped by the model.

The analysis tool runs on a free server that sleeps when nobody has used it for a while. If you see a wake-up button, press it and give it about a minute. Trouble loading? Open the tool in a new tab.
